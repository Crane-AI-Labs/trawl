How we measured

Every number on Trawl’s page comes from a real budget phone. Here is what each one means, and how we got it.

The rulesThe phonesInstall to searchPhotos a minuteSearch timeBatteryApp sizeBytes sent

The rules we keep

  • One build. Trawl 1.0.0, the same file you download.
  • Real phones, named. Each number says which phone it comes from. No emulators.
  • Battery tests run unplugged. Never while charging, because charging hides what the battery really does.
  • Repeated, not lucky. Each test runs 3 times, and we show the middle result.

What each number means

Install to search

42 seconds on a Samsung Galaxy A06 (4 GB)

What it means
How long after installing Trawl you can search your files by their names and by the words inside your documents.
How we measured
From a fresh install, with the models already downloaded, through the welcome screens, to the first search that puts the right document on the screen. About 140 everyday files on the phone: documents, pictures, screenshots, memes and short videos.

Photos a minute

126 photos a minute on a Samsung Galaxy A06 (4 GB)

What it means
How many photos a minute Trawl makes findable by what’s in them, so that a search for beach finds the beach photos.
How we measured
300 full-size camera photos, timed with Trawl open. This is Trawl’s quick first look, after which you can already search a photo by what’s in it. A slower second pass then makes those searches better, at about 11 photos a minute, and it runs best while the phone charges.

Search time

0.9 seconds on a Samsung Galaxy A06 (4 GB)

What it means
How long from typing a search to seeing answers on the screen.
How we measured
30 everyday searches over about 450 files, timed from the last letter typed to the answers on the screen. Matches by name and words show up almost at once; this is the time to the answers found by meaning.

Battery

<1% of the battery in 3 hours unplugged, on a Samsung Galaxy A06 (4 GB)

What it means
How much battery the phone used in 3 hours unplugged, with Trawl installed and idle.
How we measured
Trawl reads every file first, so it has nothing left to do. Then the phone is unplugged and left alone for 3 hours with the screen off, and we read Android’s own battery record for that time. It stayed at 100%: the battery level moves in whole percents, so the phone used less than 1%.

App size

47 MB Trawl 1.0.0 for 64-bit phones

What it means
The size of the Trawl app download. The models are a separate download: 670 MB Standard, or 304 MB Save data.
How we measured
The size of the 1.0.0 file in bytes, where one megabyte is 1,000,000 bytes.

Bytes sent

0 bytes sent Trawl 1.0.0, on any phone

What it means
How much Trawl sends over the internet. Android lets an app go online only if it asks for the internet permission. Trawl doesn’t ask, so it can’t send anything.
How we measured
We read the permissions inside the 1.0.0 file with Android’s own tools. The internet permission isn’t there.
