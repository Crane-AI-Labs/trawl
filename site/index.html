Trawl has no internet permission. It collects nothing.

Android only lets an app go online if it asks to. Trawl doesn’t ask, so your files, your searches and what it learns stay on your phone.

  • No internet permissionIt can’t send anything anywhere.
  • No accountNothing to sign up for or sign in to.
  • No ads, no analyticsNobody watches what you search.
  • Signed modelsTrawl checks the models file is genuine before using it.
  • Private previews blurredPhotos that may be private stay blurred until you tap them.
  • Delete everythingOne button removes all Trawl has learned. Your files stay.
  • Reports only if you send themYou read a problem report first, and you press Send.
  • No trackers here eitherThis website sets no cookies and loads nothing from other sites.

The search models

The part that understands your files.

Trawl’s search runs on models: files that let your phone recognise what’s in a photo and what a sentence means. They come as one separate download.

  • You choose when to spend the data.Download them once, on Wi-Fi if you can, or get the file from a friend.
  • Updates without reinstalling.Better models can arrive as a new file. The app stays as it is.
  • Checked as genuine.Every models file is signed by Crane AI Labs. Trawl refuses one that has been changed.
Most phones

Standard

670 MB

For phones with 3 GB of memory or more.

  • Photos in full detail
  • Words in documents and screenshots
  • Speech in videos and voice notes
  • Blurred private previews
Downloads less

Save data

304 MB

For any 64-bit phone, if you’d rather download less. Phones with 2 GB of memory always use it.

  • A quick look at photos
  • Words in documents and screenshots
  • No speech search
  • Weaker Luganda and Swahili photo search
  • Blurred private previews

Not sure? Choose Standard. Inside Trawl, Get the models offers both, and you can move from Save data to Standard later.

Which one is mine?

Almost every phone from the last few years is 64-bit, so start there. If Android says “App not installed”, or your phone says Android Go (many itel phones and some 2 GB phones), you need Trawl Go.

To check, open Settings › About phone. The wording differs by brand.

Install it in six steps

  1. Download the appTap Download Trawl. If your browser asks whether to keep the file, tap Download or Keep.
  2. Open the fileTap Open when it finishes, or find trawl-1.0.1.apk in Files › Downloads.
  3. Allow installs, onceIf Android says it can’t install apps from this source, tap Settings, turn this on, then go back.Allow from this source
  4. Tap Install, then OpenFollow Trawl’s first pages and allow access to your files, so it can search them.
  5. Tap Get the modelsYour browser downloads one file: 670 MB, or 304 MB if you choose Save data. Wi-Fi is best.
  6. That’s itWhen the download ends, Trawl adds the models by itself and starts learning your files. Search works within minutes.

Got the models file from a friend over Bluetooth, a sharing app or a memory card? In Trawl, tap Choose the file. You can turn Allow from this source off again afterwards. Only install Trawl from this page.

Desktop developer preview

Trawl for Windows, Mac and Linux finds the files on your computer the way the phone app does. It is free. This is a developer preview: the installers are not signed, so your computer will warn you before it lets you open them. Install one only if you are comfortable with that.

Macs with Apple silicon (M1 or newer), macOS 13 or newer. Open the file and drag Trawl to Applications. The first time, right-click Trawl and choose Open. On macOS 15 or newer, if there is no Open button, try once, then use Open Anyway in System Settings › Privacy & Security.

The models. Like the phone app, the desktop app needs the standard models file, trawl-models.zip (670 MB). Keep it in your Downloads folder and Trawl finds it. The desktop app never downloads anything itself.

Check the download. The installers are unsigned, so compare the file with its checksum on the release page (SHA256SUMS). We ran each installer for ten minutes on its own system while watching for network connections, and saw none. How to repeat the test is in the source code.

Questions

Will it work on my phone?

If your phone is 64-bit and runs Android 11 or newer, yes. Most phones sold in recent years are 64-bit. Android Go phones (often 2 GB, many itel models) are usually 32-bit: they need Trawl Go (see Download), which finds files by name and by the words in them. If Android says “App not installed”, the phone is most likely one of these.

Is Trawl free?

Yes. Trawl is free to download and use, with no ads and no account. It is open source under the Apache 2.0 licence, and the source code is on GitHub.

Will it use my data bundle?

Only once, when your browser downloads the models (670 MB, or 304 MB with Save data). Trawl itself has no internet permission, so it can’t use data at all.

How long until it finds everything?

File names and words in documents work within minutes. Photos get a quick look while you use the phone, and the full reading, which gives the best matches, happens while it charges. Trawl shows how far it has got.

Will it drain my battery?

It shouldn’t. The heavy work waits for the charger, and on battery Trawl only does light work.

Which should I get, Standard or Save data?

Standard, if you can: it is the best search in every language and it hears speech in videos and voice notes. Save data downloads less than half as much: English search is just as good, but Luganda and Swahili photo search is weaker and there is no speech search. You can move to Standard later and keep your index. A phone with 2 GB of memory always uses Save data, and a file for the wrong kind of phone is refused, so you can’t get it wrong.

Can I delete what Trawl has learned?

Yes. Settings › Delete everything Trawl knows removes it all. Your own files stay exactly as they are.

Why isn’t it on the Play Store?

It will come to the Play Store later. Until then, install it from this page.
