Check Trawl’s privacy yourself

Trawl by Crane AI Labs says it cannot send your files anywhere. You don’t have to take our word for it. This page says what we claim, what the claim rests on, and how anyone can check it.

What we claim

  • No internet permission. The Trawl app cannot go online.
  • No account. There is nothing to sign up for or sign in to.
  • No ads, no analytics. Nobody watches what you search.
  • Reports only if you send them. You read a problem report first, and you press Send.
  • This website sets no cookies and loads nothing from other websites.

Why the internet permission matters

Android’s own documentation describes the internet permission as one that “allows applications to open network sockets”. A network socket is how an app talks to the internet. An app that does not have the permission cannot open one.

Android grants this kind of permission automatically when an app is installed, without asking you. Its developer documentation says: “The system automatically grants your app the permissions when the user installs your app.” That is why you never see a pop-up for it, and why the way to know is to read the list of permissions an app asks for.

Android applies permissions to the whole app, including every code library inside it. So when the permission is absent, nothing inside Trawl can go online either.

Sources: Android Manifest.permission reference and Permissions on Android, read 21 October 2026.

What we found in the Trawl files

We read the permissions inside the 1.0.0 files of both editions, Trawl and Trawl Go, on 21 October 2026, with the tools that come with Android. The internet permission is not there. Both files ask for the same nine kinds of permission, listed here with what each one is for.

All files accessMANAGE_EXTERNAL_STORAGERead documents anywhere on the phone.So Trawl can search them. With no internet permission, it cannot upload them.
Photos, videos and audioREAD_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_AUDIORead those kinds of files.So Trawl can search them.
Selected photos onlyREAD_MEDIA_VISUAL_USER_SELECTEDAndroid’s option to share only the photos you pick.So Trawl still works if you choose that option.
NotificationsPOST_NOTIFICATIONSShow a notification.So Trawl can show how far it has got.
Unlock promptUSE_BIOMETRICUse Android’s own unlock prompt: fingerprint, face, or the phone’s PIN or pattern.For Trawl’s app lock. Android does the checking, and Trawl never sees your fingerprint or face.
Long reading runFOREGROUND_SERVICE, FOREGROUND_SERVICE_DATA_SYNCRun with an ongoing notification.So the overnight reading of your files can finish.
Keep awakeWAKE_LOCKKeep the phone awake while it works.Comes with a code library Trawl uses for background work.
See the networkACCESS_NETWORK_STATEAsk Android whether the phone is connected.Comes with the same library. Android describes it as “access information about networks”. It does not let an app send anything.

Each file also has one permission with Trawl’s own name on it, which only Trawl’s own parts can use. Three of the rows above (keep awake, see the network, restart after a reboot) come with a library Trawl uses for background work, not from Trawl’s own list.

Check it yourself

On the phone, in a minute

  1. Download Trawl and install it. Download the models once, with Wi-Fi.
  2. Turn on Airplane mode, and turn Wi-Fi off.
  3. Open Trawl and search. It works exactly the same.

This shows that searching does not need the internet. It does not, by itself, show that nothing is sent while you are online. The permission list does that.

On a computer, in two minutes

  1. Download the Trawl file (the APK) from the release page, and keep it on the computer.
  2. Get Android’s free command-line tools from developer.android.com. They include apkanalyzer.
  3. Run the command below, and read the list.

The release notes list a checksum for each file and the signing certificate’s fingerprint, so you can check you have the genuine file.

The command, and what it printed for Trawl 1.0.0

$ apkanalyzer manifest permissions trawl-1.0.0.apk
android.permission.READ_MEDIA_VIDEO
android.permission.READ_MEDIA_AUDIO
android.permission.FOREGROUND_SERVICE
android.permission.READ_MEDIA_IMAGES
android.permission.RECEIVE_BOOT_COMPLETED
android.permission.MANAGE_EXTERNAL_STORAGE
android.permission.READ_MEDIA_VISUAL_USER_SELECTED
android.permission.USE_BIOMETRIC
android.permission.ACCESS_NETWORK_STATE
android.permission.WAKE_LOCK
android.permission.POST_NOTIFICATIONS
android.permission.FOREGROUND_SERVICE_DATA_SYNC

The tool printed one more line, for the permission with Trawl’s own name, which we left out. Look for android.permission.INTERNET: it is not in the list. Run the same command on Trawl Go’s file and the list is the same. A developer can run aapt2 dump permissions instead, and gets the same answer.

What this does not cover

The one time you go online

Trawl’s Get the models opens your browser on the right file, and your browser downloads it. Trawl itself sends nothing. This is the only time Trawl needs you to go online.

Things you choose to send

A problem report goes out through another app on your phone, and only after you have read it and pressed Send. Trawl does not send it by itself.

Only the version we checked

We checked version 1.0.0. A later version could ask for different permissions, so the check is worth repeating after an update. This page will say which version it covers.

Other apps on your phone

The permission covers Trawl, not the other apps on your phone. Your browser, your chat apps and your keyboard have their own permissions.
