- **Choose how much to download.** On the first run and in Settings you can pick **Standard** (670 MB, recommended) or
  **Save data** (304 MB). Save data finds documents and screenshots in English just as well. Its Luganda and Swahili photo search is
  weaker, and it doesn't listen to videos or voice notes. You can move from Save data to Standard later: your list of files stays,
  and Trawl reads them again with the better model. A phone with 2 GB of memory always uses Save data, as before.
- **No more jump when you come back.** If you left Trawl with search results on screen, reopening it no longer brings the keyboard
  back and jolts the page. You return to exactly what you left.
- **Your language.** The new screens are in all 13 languages Trawl speaks.

Already on 1.0.0? Install 1.0.1 over it. It has the same signing key, so your index and settings stay.

Trawl never changes, moves or uploads your files. It has no internet permission at all.
