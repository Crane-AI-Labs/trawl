- **No more crash on Snapdragon phones.** On phones with a Qualcomm Snapdragon chip (for example recent Samsung Galaxy S
  phones), Trawl could crash in the background while it put its picture model away. It now keeps that model safely loaded
  instead.
- **Setup asks to let Trawl keep reading.** After "All files access", setup now asks to let Trawl keep reading when you're
  not using it, so Android stops putting it to sleep. It still waits while you use another app. "Not now" always works, and
  you can change it later in Settings.
- **Tablets look right.** On a tablet, the home screen, results and Settings now sit in a comfortable column instead of
  stretching across the screen. Photo grids use the extra width for more columns.
- **Problem reports say Trawl.** Reports you choose to send are now named Trawl throughout.

Already on 1.0.0, 1.0.1 or 1.0.2? Install 1.0.3 over it. It has the same signing key, so your index and settings stay.

Trawl never changes, moves or uploads your files. It has no internet permission at all.
