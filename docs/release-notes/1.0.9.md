- **Previews no longer end halfway through a word.** The short preview under a file that Trawl finds by meaning could, in rare
  cases, stop in the middle of a very long word such as a web address, or split an emoji or an accented letter in two. It now
  ends at the edge of the word. This changes only the preview text, not which files you find or their order, and it applies to
  Trawl and Trawl Go.

- **A cut-off model download no longer says "damaged".** If the search models download stopped partway, Trawl now says the
  download did not finish and that tapping the download button again lets your browser continue it, instead of starting the
  670 MB again. If the search model is already installed, Trawl says so and names only the packs that are still missing. It
  applies to Trawl; Trawl Go has no separate model download.

- **A slow file no longer loses meaning search for good.** Trawl reads each file in short steps. If a step took too long (for
  example, a long document full of codes or random-looking text on a slower phone), the file used to be marked as failed and
  could only be found by its words and name until the next update. Now Trawl keeps the part it finished and continues the rest
  later, the same way it already does for long documents.

- **The first search after opening Trawl now catches up.** Right after Trawl starts, the part that searches by meaning takes a
  moment to get ready. A search typed in that moment could stay on word matches only. Now the results refresh once, by meaning,
  as soon as it is ready.

Already on 1.0.0 to 1.0.8? Install 1.0.9 over it. It has the same signing key, so your index and settings stay.

Trawl never changes, moves or uploads your files. It has no internet permission at all.
